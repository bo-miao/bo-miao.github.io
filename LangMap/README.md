# LangMap Project Page

This directory contains the static project page for:

**LangMap: A Human-Verified Benchmark for Hierarchical Goal Navigation**

LangMap introduces HieraNav, a hierarchical open-vocabulary goal navigation task, and provides human-verified annotations across object, room, region, and instance levels.

## Links

- Project page: https://bo-miao.github.io/LangMap/
- Paper: https://arxiv.org/abs/2602.02220
- Code and data: https://github.com/bo-miao/LangMap
